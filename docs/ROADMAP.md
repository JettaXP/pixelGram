- Capsule folder bar: the active pill still isn't a scaled-down copy of the
  whole capsule — the proportions must match.
- Standard Material folder bar on top looks like a slightly changed capsule;
  it must use the same Material 3 navigation items as the side rail. Check
  the official Google Material 3 libraries for the correct component.

## Window and system tray

- Closing the window hides pixelGram to the system tray instead of quitting.
- Tray menu:
  - **Open pixelGram** — shows the window again;
  - **Disable notifications** — a button that mutes notification sounds and pop-ups;
  - **Quit pixelGram** — closes the app completely.
